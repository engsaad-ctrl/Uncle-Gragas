# Uncle Gragas

مساعد شخصي على Windows للعبة League of Legends (Electron + TypeScript). واجهته عربية وأسماء الأبطال والأيتمات بالإنجليزية، ويستخدمه ثلاثة أشخاص.

## الفكرة

عندما تختار بطلاً في شاشة الاختيار يقرأ البرنامج حالة اللعبة من عميل اللعبة (LCU) ويجهّز لك كل شيء قبل بداية المباراة:

- **البناء التلقائي**: يطبّق صفحة الرونز والتعاويذ (مع وضع Flash على D أو F حسب الإعداد) ومجموعة الأيتمات، وذلك عند تأكيد الاختيار (Lock-in) لا عند المرور على البطل.
- **صفحة البطل**: البناء الأساسي، ترتيب المهارات، الرونز، الأيتمات، والتعزيزات مرتبة حسب الأفضل لهذا البطل، مع نصوص دقيقة وأرقام صحيحة من ملفات اللعبة.
- **Tier List**: لكل طور (Ranked، ARAM، Mayhem) مع الترتيب حسب أي عمود والبحث. ARAM وMayhem بدون مسارات.
- **بطاقة F7 داخل المباراة**: نافذة فوق اللعبة تعرض البناء والتعزيزات مجمعة حسب النوع وبترتيبها لهذا البطل. في Mayhem تضغط «اخترته» على التعزيزات التي أخذتها فيُعاد ترتيب الأيتمات حسبها مع ذكر السبب.
- **التعرف على الطور**: Ranked، ARAM، Mayhem (queue 2400 أو map 12)، Arena.
- **التحديث الذاتي**: من إصدارات GitHub (electron-updater).

## مصادر البيانات

- **CommunityDragon**: ملفات اللعبة ونصوص الأبطال والأيتمات والتعزيزات.
- **خادم MCP لموقع إحصائيات**: البناءات ونسب الفوز والتعزيزات لكل بطل. اسم الموقع لا يظهر في الواجهة.
- **LCU**: عميل اللعبة على جهاز اللاعب.

## قواعد ثابتة

- لا قراءة لذاكرة اللعبة، ولا تحايل على حماية المواقع من البوتات.
- لا يظهر اسم موقع الإحصائيات في الواجهة.
- ملفات التشخيص تحذف الأسماء والمعرّفات والرموز.
- في الواجهة نكتب «أيتمات»، وفي نصوص اللعبة «عنصر».
